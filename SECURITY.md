# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities publicly before maintainers have had a chance to assess them.

Until a private security contact is published, open a GitHub Security Advisory if the repository has private vulnerability reporting enabled. Otherwise, contact the maintainers through the private contact method listed in the repository profile.

Include:
- A description and potential impact.
- Reproduction steps or a minimal proof of concept.
- Affected versions and Windows configurations.
- Any suggested mitigation.

Do not include personal data, credentials, or unrelated system information.
